# Proposed image prompt structure (Phase 5)

Keep prompts short enough that exact text and safety constraints win attention.

## Order (priority)

1. **Objective** — one sentence: what residents must understand.
2. **Selected concept** — one short visual concept (or “execute attached strategy summary”).
3. **Exact required text** — headline + message verbatim; “render exactly; minor punctuation only.”
4. **Mandatory safety** — do not show unsafe behavior as recommended; no gore; invisible hazards stay invisible (no fake CO cloud/smoke).
5. **Branding** — attach real logo or forbid invented seals.
6. **Essential design** — style + 3–5 visual details max; phone readability.

Then stop. Do **not** repeat the same rule in five sections.

## What to remove from Phase 2 mega-prompts

- Duplicated negative lists (28–32 “do not” lines).
- Long composition essays competing with text fidelity.
- Micro-managing every lighting/negative-space decision.

## Modes

- **Native AI:** short headline/message + concept.
- **Hybrid:** ask model for **text-free artwork** matching concept; composite exact text/logo with Sharp/Canvas.
- **Accuracy-first:** verified diagram / constrained illustration path for equipment-critical topics.
